#REQUIREMENTS 

Languages / runtime:
Python — developed and tested on Python 3.12, but anything 3.8+ will work fine (no modern syntax features beyond that are used).
Framework:
Flask — tested with Flask 3.1.3 (current stable). Any Flask 2.x or 3.x will work
Frontend:(no installation needed — runs in the browser)
Plain HTML5
Plain CSS3 (no Sass/Tailwind/build step)
Plain JavaScript (vanilla, no React/Vue, no npm packages)
Two Google Fonts loaded via CDN link in index.html (Orbitron + Rubik + JetBrains Mono) — no install needed, just needs internet access when the page loads
Storage:
A plain data.json file — no SQLite, no database server, no ORM.
